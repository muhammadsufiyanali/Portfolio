# Muhammad Sufiyan Ali: Portfolio

Personal portfolio website of **Muhammad Sufiyan Ali**, a Full Stack Developer.

## Sections
- Hero with typing effect
- About with stats
- Services (web, apps, games, SEO, design)
- Tech stack
- Projects with filters (linked to GitHub)
- Work process
- Contact form (opens email) + WhatsApp / email links

## Tech
Plain **HTML, CSS and JavaScript**. No build step, fully responsive.

## Run locally
Open `index.html` in a browser.

## Deploy on GitHub Pages
Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save.
The site will be live at `https://muhammadsufiyanali.github.io/Portfolio/`.
